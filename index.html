Portafolio web personal

HTML · CSS · JavaScript
  • Diseñé y codifiqué desde cero la estructura en HTML semántico y el diseño visual en CSS, con variables de color para alternar automáticamente entre modo claro y oscuro, y una cuadrícula responsiva que se adapta a computador, tablet y celular.

  • Ajusté el diseño en varias iteraciones a partir de retroalimentación recibida, mejorando la jerarquía visual, la navegación y la presentación de la información técnica.
